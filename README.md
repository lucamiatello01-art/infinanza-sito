# infinanza.net

Sito pubblico di **Infinanza**, progetto editoriale di educazione finanziaria
(@in.finanza su Instagram, TikTok e YouTube).

Sito statico servito da **GitHub Pages** sul dominio `infinanza.net`.
Nessun database, nessun modulo: ogni richiesta arriva per posta all'indirizzo
indicato nelle pagine.

| pagina | cosa contiene |
|---|---|
| `index.html` | home |
| `guida.html` | la guida |
| `privacy.html` | informativa privacy |
| `termini.html` | termini di servizio |
| `whatsapp.html`, `caption.html`, `grazie.html` | pagine di supporto |

I due file `tiktok*.txt` sono i file di verifica del dominio per la piattaforma
TikTok for Developers: **non vanno rimossi**, o la verifica del dominio decade.
Il file `CNAME` tiene il dominio personalizzato; `.nojekyll` disattiva Jekyll.
